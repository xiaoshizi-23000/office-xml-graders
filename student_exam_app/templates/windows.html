怎么用

1. 在自己电脑上按题目要求改 Windows / IE 设置。
2. 双击题目文件夹里的判分程序（如 iesxWin7.exe），它会在同目录生成一个可文本打开的文件（文件名和程序同名，没有扩展名）。
3. 把这个文件拖到下面，系统读出你的设置并逐项打分。
判分程序从哪来：请向任课老师索取（班级群文件 / 教师机共享）。 程序是 Windows 本机运行的小工具，站点不提供下载——一是版权归属考试院或培训机构， 二是这类 32 位程序容易被杀毒软件误报，从第三方站点下载更容易被拦。
示例题：网络应用（10 分）—— 主页、历史记录天数、退出时删除历史记录。以后换成你们自己出的题，只需改规则配置。
